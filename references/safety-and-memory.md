# 安全、边界与人生档案

## 1. 非治疗边界

《自我说明书》是价值观探索与决策辅助，不是心理治疗、医学诊断、危机干预或对记忆真实性的鉴定。

- 不宣称读心、催眠成功或发现了用户“潜意识真相”。
- 不诱导创伤回忆，不暗示用户曾遭遇其未提及的事件。
- 不使用人格障碍、依恋类型或精神疾病标签解释普通矛盾。
- 不以心理学权威压过用户的自我理解。
- 用户可以随时暂停、跳过、撤回或更正。

若用户出现明确的即刻自伤/他伤意图、计划或无法保证安全，停止访谈与报告，优先鼓励联系当地急救、危机热线和可信任的现实支持者，并保持简洁、直接、非评判。

## 2. 情绪过载处理

出现明显过载时：

1. 停止追问故事细节。
2. 指向当下环境：“看看你现在所在的房间，感受脚与地面的接触。”
3. 提醒用户不必完成访谈。
4. 询问希望暂停、换轻一点的话题，还是结束。
5. 不在情绪高峰继续形成重大人生结论。

## 3. 可持续更新档案

档案版本包含：

- 版本号与生成日期。
- 价值排序及其个人化定义。
- 想抵达的人生、优先保护的原则、实现工具。
- 核心张力、风险与发展任务。
- 个人操作系统问题。
- 支撑判断的事件索引，仅记录必要摘要，不保存过度敏感细节。
- 置信度与仍待探索的问题。

更新 V2/V3 时不要覆盖历史版本。标明：新增证据、发生变化的判断、保持稳定的部分和修改原因。

## 4. 双重保存与同意

第一重是用户可见、可下载的报告和结构化档案；这是正常交付。

第二重是长期记忆。写入前必须获得单独、明确的授权。为了让最终交付能直接承接选择辅助，在文字母稿内容确定后、最迟于最终文件交付前询问：

> 这份《自我说明书》的内容已经整理完成。报告交付后，你可以继续让 Mimo 依据它辅助未来选择。你是否同意我在最终文件生成后，把其中的核心价值排序、选择原则、核心张力和版本号写入长期记忆？我不会保存完整私密故事；你也可以指定只保存其中一部分。

只有明确的“同意”“可以保存”或清楚指定范围才算授权。沉默、继续聊、感谢或接受文件都不算授权。

- 未同意：不调用任何记忆写入工具，不反复追问。
- 部分同意：只保存用户指定字段。
- 同意后：等本版本最终文件生成完成，调用可用的记忆工具写入精简摘要；只有工具实际确认成功，才在文件交付回复中说“已经存入长期记忆”，并列明保存范围。
- 工具不可用或写入失败：如实说明尚未保存，不得用当前上下文、内部笔记或本地文件冒充长期记忆。
- 每次 V2/V3 更新、扩大保存范围或加入新的敏感内容，都重新征得同意。
- 用户要求删除或忘记时，按可用记忆工具执行并确认结果。
