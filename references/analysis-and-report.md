## 1. 内部分析方法

### 建立隐藏的证据账本

访谈结束后，先在内部整理，不直接展示表格：

| 字段 | 内容 |
|---|---|
| 事件 | 发生了什么 |
| 行动 | 用户实际选择了什么 |
| 代价 | 时间、金钱、健康、关系、身份、稳定等 |
| 当时动机 | 用户原话与合理推断分开 |
| 事后评价 | 后悔、不后悔、复杂、仍未解决 |
| 候选价值 | 自主、连接、创造、成长等，不限预设词表 |
| 反证 | 与候选价值冲突的事件或表达 |
| 置信度 | 高 / 中 / 低 |

证据强度从高到低：高代价行为选择 > 跨情境重复行为 > 事后长期评价 > 强烈情绪 > 自我描述 > 对未来的幻想。

不要因为用户说“我重视家庭”就把家庭列为核心价值；查看其选择、代价与冲突中是否持续保护它。也不要因一次创伤性回避就把相反方向判定为价值。

### 形成三层结构

必须区分：

1. **想抵达的人生**：用户希望长期生活在怎样的关系、事业与日常中。
2. **选择时优先保护的原则**：即使付出代价，也不愿长期交出的东西。
3. **实现路径与工具**：能力、金钱、学历、职位、城市、关系形式等。

同一概念可能承担不同层级。不要强行把所有内容排在一条价值榜上。

### 形成核心判断

完成报告前，内部必须能用一句话回答：

> 这个人想用什么方式，建设一种怎样的人生；最不能背叛什么；目前最需要学会什么？

若答不出，说明证据尚未整合，不要进入视觉制作。

## 2. 心理学使用原则

可按材料选择理论，不必每份报告全部使用：

- 自我决定理论：自主、胜任、关系需要。
- 叙事身份：用户如何把过去组织成“我是谁”的故事。
- 依恋与安全基地：关系如何支持或限制探索；不得仅凭片段判定依恋类型。
- 心理抗拒：自由受威胁时恢复自主的倾向。
- ACT 价值观：持续实践的方向与可完成目标的区别。
- 动机性访谈：矛盾、改变语言、自我效能。
- 意义建构、损失厌恶、沉没成本、身份保护等适用机制。

每个理论只做三件事：解释可观察模式、指出适应性功能、帮助用户形成下一步行动。不要堆理论名制造权威感。

使用“可能”“更像是”“一个较能解释现有材料的假设”。除非有专业诊断材料，否则禁止诊断人格障碍、抑郁症、焦虑症、创伤或依恋类型。

### 每个核心价值的深析公式

用连续文章完成以下内容，不把它们机械做成六个小标题：

1. 给出专属于此人的定义。
2. 融入 1–2 个最有解释力的生活片段。
3. 解释该模式可能如何形成、满足什么心理需要。
4. 说明它目前怎样保护和推动用户。
5. 指出优势走到极端时的风险。
6. 给出更成熟、可持续的表达方式。

目标是让用户读到的不只是“你重视自由”，而是“为什么自由对你如此重要、你过去如何守护它、它怎样救过你、又可能怎样误导你”。

## 3. 先形成完整文字母稿

视觉制作开始前，先生成一份完整 Markdown 报告。它必须在没有图片、颜色和版式帮助时，仍然清楚、深刻、具有指导性。

文字母稿是内容的单一事实来源：

- 所有核心结论、排序、心理解释、风险和建议先在 Markdown 中完成。
- 不在 HTML 阶段临时补写重要洞察，也不在 PDF 阶段删掉装不下的段落。
- 若排版装不下，应调整页数、字号范围内的排版或章节布局，而不是牺牲分析。
- 视觉稿允许对标题做不改变意义的短化，但正文和结论不得悄悄改写。
- 若用户要求先审阅内容，交付 Markdown 后暂停；否则完成内部验收后可以继续渲染。

### 文字母稿开头必须有一页式摘要

让用户无需通读全文便能明确获得：

1. 一句统领全篇的核心判断。
2. “你想获得的人生”前三项。
3. “你做选择时应优先保护”前三项。
4. 核心价值观 1、2、3 的个人化名称与一句定义。
5. 当前最重要的三项发展任务。
6. 最优先的三条行动建议。

摘要不是正文替代品。正文必须继续解释这些判断如何形成、为何成立、何时会失衡以及如何应用。

## 4. 固定报告骨架

默认制作 10–14 页 A4 纵向报告；内容不足时宁可缩短，不注水。

### 01 封面

- 《[姓名]的自我说明书》与版本号。
- 一句只属于用户的精神副标题，不使用“勇敢、善良、自由、成长”式通用口号。
- 用一个主视觉隐喻，不堆满装饰。

### 02 结果总览

必须在一页内清楚展示：

- **你想获得的人生**：排序 1–3。
- **你做选择时应优先保护**：排序 1–3。
- **你当前最重要的发展任务**：3 项。

这是用户“看完有所得”的导航页，不能藏到结尾。

### 03 结论先行的人格画像

以 500–900 字连续陈述回答“你究竟是怎样的人”。整合看似矛盾的特质，给出一条统领全篇的判断。加入简短的非诊断边界说明。

### 04 心理结构图

用一个清楚模型展示价值之间的关系，例如：终点 / 否决权 / 能力路径 / 支撑条件，或自主 / 胜任 / 连接。模型必须由用户材料推导，不能硬套 MBTI、星座或固定人格分类。

### 05–08 核心价值深析

以 3 个主价值为默认；证据充分时加入第 4 个支撑价值。每项约 700–1200 字，使用“深析公式”。每章末尾可用一行极简结论表达：它保护什么、失衡会怎样、成熟形态是什么。

### 09 整合画像与核心张力

解释价值如何共存和冲突。重点写“既……又……”背后的统一逻辑，不只是重复前文。指出用户最有辨识度的人格组织方式。

### 10 风险与发展课题

写 3–4 个由优势延伸出的风险。每项都说明：触发条件、心理原因、现实表现、校准方向。语气不审判，不把风险写成缺点清单。

### 11 个性化建议

按优先级给 3–5 条。每条包含：

- 一个可记住的标题。
- 为什么这条只适用于此人。
- 具体行动或实验。
- 可观察的判断标准。

建议应覆盖长期建设、当下幸福、事业/关系中的关键课题；不必面面俱到。

### 12 个人操作系统与尾声

- 给出 4–6 个重大选择问题，每题都紧扣用户的价值冲突。
- 用温暖而克制的尾声完成情绪收束。
- 标明版本、日期、更新机制和记忆同意状态。
- 在配置了真实 URL 时加入 GitHub 推广区；若 URL 未配置，不得编造链接或向最终用户显示“链接待补充”。

## 5. 写作标准

### 要做

- 先清晰，后动人；结构与文学性并存。
- 主要使用完整段落，保持正常长文阅读节奏。
- 大胆写出整合性判断，但把判断表述为可修正的解释。
- 引用用户原话时保持克制，每章 0–1 处即可。
- 让心理分析回答“为什么”，让建议回答“以后怎么办”。
- 保留用户的复杂性，不把矛盾消解成单一标签。

### 不要做

- 不要连续罗列证据、时间线或访谈摘要。
- 不要把报告写成占卜、鸡汤、人格测试结果或病例。
- 不要用大量短句、每句换行、巨型引语和空白制造虚假高级感。
- 不要每一页都用卡片网格；深度内容应以文章排版为主。
- 不要把理论名称当结论，不要引用用户未表达过的创伤故事。
- 不要给“坚持自己、相信自己、勇敢前行”之类通用建议。
- 不要为了凑页数重复同一洞察。

### 最低内容深度

完整报告正文通常不少于 5,000 个中文字符。篇幅不是目标；若一个判断没有“个人表现＋心理解释＋风险校准＋应对方式”，它就还不够深。

## 6. 选择辅助输出

针对具体选择，输出 5 个部分：

1. **真正的问题**：把表面选项还原为价值冲突。
2. **你的排序**：哪些价值是终点、底线和工具。
3. **选项比较**：逐项说明收益、代价、可逆性、能力积累与关系/健康影响。
4. **Mimo 的倾向**：给出清晰倾向、置信度和改变建议所需的新信息。
5. **最小验证**：在不可逆决定前设计一个低成本现实实验。

不要把所有维度简单加权成总分。某些底线拥有否决权；某些短期损失可换长期能力。必须解释权重来源。

## 7. 文字母稿验收门

先只审查 Markdown，不考虑视觉美感。逐项通过后才能调用设计技能：

- **结构清晰**：一页式摘要、价值排序、深析、风险、建议和决策系统完整，层级无重复。
- **结论明确**：用户能直接指出“我的核心价值观是 1、2、3；建议是 1、2、3”。
- **分析够深**：每个核心价值都包含个人表现、可能成因、心理功能、失衡风险和成熟表达。
- **真正个人化**：删除姓名后，报告仍不能轻易套在大多数人身上；至少有三条高辨识度整合判断。
- **证据不出戏**：关键经历被自然融入论证，没有访谈流水账或证据清单。
- **建议有用**：建议包含原因、行动和可观察标准，并与分析逐项对应。
- **正常阅读**：以完整段落为主，不依靠碎句、巨型引语和空白制造情绪。
- **边界可靠**：心理学只作解释假设，无诊断、读心或超出材料的创伤推断。

若任一项不通过，先重写文字母稿。视觉设计不得用来补救内容空洞。

## 8. 最终交付验收

逐项自检；任一核心项不通过就先修改：

- 用户能否在 60 秒内说出自己的前三价值与前三建议？
- 是否至少有三处让熟悉用户的人觉得“这只能写给他/她”？
- 每个主要结论是否可追溯到行为或代价，而非只来自自我宣称？
- 是否解释了“为什么”，而非只给标签？
- 是否同时写了价值的保护作用、失衡风险与成熟表达？
- 建议是否具体到可以在现实中执行和判断？
- 是否区分了想抵达的生活、选择底线和实现工具？
- 是否避免证据清单、碎片排版、空白浪费和通用鸡汤？
- 是否没有心理诊断和过度确定性？
- HTML 与 PDF 是否无溢出、错页、空白页、裂图和控制台错误？
- Markdown、HTML 与 PDF 的标题、排序、核心结论、建议是否一致？
- 最终回复是否在文件链接后如实说明了长期记忆状态？
- 是否给出了可直接复制的选择辅助提问示例，并邀请用户现在提出第一个真实问题？
- 是否避免以“文件已生成”或泛泛的“有需要再找我”结束对话？
