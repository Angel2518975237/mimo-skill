## 1. 核心原则

采用“统一骨架＋个性化视觉”。报告的信息顺序、阅读密度和质量标准保持稳定；颜色、主视觉、纹理、章节意象和细节装饰从用户的价值结构与叙事气质中推导。

只有在完整 Markdown 文字母稿通过内容验收后，才调用 `$huashu-design`，并告诉用户该技能正在帮助完成报告的视觉设计。已有明确素材库和参考方向，不走三版风格探索；直接基于内容生成一个主方案，并保留旧版本。

文字母稿是唯一内容源。设计阶段不得重新解释用户、改变价值排序或因页面空间删除分析；若内容与版式冲突，以内容完整性为先，增加页数或重组版面。

视觉不是人格分类。不要写“自由型人格统一用蓝色”之类僵硬映射。先理解此人的矛盾与精神主线，再选择能承载它的组合。

## 2. 视觉人格推导

在设计前形成一份隐藏的 visual brief：

- **一句精神母题**：如“走向远方，也把灯点亮”。
- **主要张力**：自由与归属、野心与温柔、秩序与探索等。
- **主意象**：只能选 1 个统领全篇，如门、海、树、灯、豹、月亮、花园。
- **辅助意象**：最多 2 个，用于章节分隔。
- **色彩温度**：冷静 / 温暖 / 明亮 / 夜色 / 丰盛，解释其与用户材料的关系。
- **材质**：纸张、油画、金箔、水纹、雾、植物、织物等，最多 2 种。
- **版式气质**：书籍、纪录片字幕、私人档案、艺术画册中的一种为主。

### 六类意象不是六类人格

素材库包含六个入口，可混合使用：

- **自由地平线**：远方、可能性、呼吸感、方向权。
- **内心家园**：爱、归属、安全基地、共同生活。
- **生长之路**：学习、积累、年轮、长期建设。
- **穿越之门**：转折、选择、告别旧身份、进入新阶段。
- **静水深处**：内省、敏感、复杂情绪、未言明的需要。
- **力量图腾**：生命力、保护、野心、尊严、边界。

不要一章配一类、平均分图。选择与报告主线最吻合的 2–4 张，重复使用色彩和纹理建立统一性。

## 3. 素材库路由

素材位于 `assets/visual-library/`，按上述六类分文件夹。使用前生成或查看缩略图，确认构图、文字水印、清晰度与色彩。

规则：

- 优先用作裁切后的封面、跨页章节条幅或低透明度纹理，不要把手机壁纸原图生硬铺满 A4。
- 避免让原图中的平台水印、时间、锁屏文字成为报告视觉中心；能安全裁切则裁切，不能则换图。
- 不伪造图片来源或版权状态。若报告公开发布，需由项目所有者确认素材授权；个人交付也应保留资产清单。
- 文本必须保持高对比，不在复杂图像上直接压大段正文。
- 每页最多一个强视觉焦点。装饰不能抢走对用户分析的阅读注意力。

## 4. 固定版式骨架

- A4 纵向，10–14 页。
- 正文采用适合中文长阅读的宋体/衬线字体；界面标签可用克制的无衬线字体。
- 正文有效行宽约 32–40 个汉字，行高 1.65–1.9，字号打印后不低于约 10.5pt。
- 页面底部使用轻量页码和章节名；不要做厚重导航栏。
- 总览页允许排名结构；深析页以连续文章为主。
- 每 2–3 页设置一次节奏变化，如窄幅图片、拉句或结构图，而非每段都做卡片。
- 留白服务于层级与呼吸，但正文页不应出现超过约三分之一的无意义空白。
- 结果总览、建议和决策系统可以高密度；封面和尾声可以更有情绪空间。

推荐色彩数量：1 个深色文字、1 个纸张底色、1 个主色、1 个辅助色、1 个金属或高亮色。禁止默认紫色科技渐变、Emoji 图标阵列、圆角卡片海洋和通用 SaaS 风格。

## 5. 技术与验收

交付顺序：

- 完整 Markdown 文字报告；任何人仅阅读它也能获得全部洞察与建议。
- 忠实渲染文字母稿、可独立打开的 HTML；外部图片需内嵌或随报告放入稳定的相对路径。
- 从最终 HTML 渲染的 A4 PDF；文字应可搜索，优先使用浏览器打印的矢量文字而非整页截图。
- 可选的结构化 `profile.json`，供未来 V2/V3 更新和选择辅助读取。

必须完成：

1. 在浏览器中检查 HTML，确认控制台无错误、图片无裂图。
2. 逐页检测 A4 页面溢出。
3. 导出 PDF，检查页数和纸张尺寸。
4. 将所有 PDF 页面渲染为图片并查看整套缩略图；再抽查总览页、最密正文页、建议页和尾页原尺寸。
5. 确认没有孤行、截断、空白溢出页、过小文字或重复内容。
6. 对照 Markdown 抽查总览、所有价值排序、每章结论和行动建议，确认视觉版无删漏或含义漂移。

## 6. GitHub 推广区

报告尾页加入克制的项目推广，不让广告破坏私人报告体验：

- 标题：`在 GitHub 关注《自我说明书》Skill`
- 一句说明：邀请用户收藏、反馈或共同完善这套人生决策工具。
- 使用 `config/project.yaml` 中的 `github_url` 生成可点击链接和可选二维码。
- 若 URL 为空：在制作报告前向项目所有者询问；当次拿不到时先省略推广区，不向最终用户展示占位符，也不编造地址。
